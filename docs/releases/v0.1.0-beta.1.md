# Modelith 0.1.0-beta.1

開いたときに、前回の続きから始めるようになりました。0.1.0 に向けた最初の beta 版で、機能はここで固定し、0.1.0 までは不具合の修正だけを行います。

## 新しい機能

- 前回の続きから始める：Modelith を開き直すと、前回開いていたフォルダとファイル、表示していたファイル、図のタブがそのまま戻ります。保存先の無いファイル（新しいファイル・サンプル）も、これまでどおり下書きから戻ります
- 「前回の続きを開く」：フォルダを読み直すのにブラウザの許可が要るときは、サンプルの代わりに「前回の続きから始められます」と表示します。「前回の続きを開く」を押してブラウザの確認で許可すると、1 回の操作で前回の続きに戻ります
- 起動時にサンプルを開く：「ファイル」メニューの「起動時にサンプルを開く」をオンにすると、これまでどおり、開いたときにサンプルを表示します

## その他

- 機能の固定：この版で 0.1.0 の機能を固定しました。0.1.0 までは、不具合の修正だけを行います。気になる振る舞いがあれば、[GitHub Issues](https://github.com/modelith/modelith/issues/new/choose) でお知らせください
- 開発段階の表示：画面左上の札と「ヘルプ」に、beta 版であることを表示します

## 0.1.0-alpha.10 をお使いの方へ

- 開き直したときに、サンプルではなく前回の続きが表示されるようになります
- 前回開いていたファイルを、そのあと Modelith の外で消したり名前を変えたりしていたときは、そのファイルは開かずに、「見つかりませんでした」とお知らせします

# リリースノート

Modelith の各バージョンで変わったことです。いまは 0.1.0 に向けた beta 版です。0.1.0 までは、不具合の修正だけを行います。
ダウンロードやタグは [GitHub Releases](https://github.com/modelith/modelith/releases) にもあります。

## 最新：0.1.0-beta.6

トレースの抜けを、図を見たまま見つけて直せるようにした版です。機能は beta.1 のまま固定しています。

- 図のサブバーの「トレースの抜け N 件」を押すと、図のまま抜けのある要求を選んで図の中央に出し、何が足りないかと直し方を示すようにしました。その場で「関係を追加」を押して直せます
- 抜けが複数あるときは、案内の「1 / 3 件目」と「‹」「›」で順に移れます。抜けのある要素の箱には △ の印が付きます
- 要求から検証や部品へ線を引いたときも、「この検証で確かめる «verify»」「この部品で満たす «satisfy»」などを選べるようにしました（どちらの要素から線を引いても選べます）
- トレースの抜けの文で、要求の名前が 2 回出ていたのを直しました

[0.1.0-beta.6 のリリースノート](/releases/v0.1.0-beta.6)

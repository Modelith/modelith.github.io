# リリースノート

Modelith の各バージョンで変わったことです。いまは 0.1.0 に向けた alpha 版を、おおむね 1 週間ごとに公開しています。
ダウンロードやタグは [GitHub Releases](https://github.com/modelith/modelith/releases) にもあります。

## 最新：0.1.0-alpha.9

振る舞いを図に描けるようになりました。

- [アクティビティ図](/diagrams/activity) — アクション定義の流れを、開始・終了・分岐・合流などの記号で描きます。図の上で線を引くと順序を書き足します
- [状態遷移図](/diagrams/state-machine) — 状態定義の状態と遷移を描きます。ツリーの状態定義の「開く」で開きます
- [シーケンス図](/diagrams/sequence) — ライフラインの上のイベントと、その順序を描きます
- [語の説明](/guide/screen#語の説明) — テキストの語にマウスを乗せると、その意味を表示します
- [スマホの画面](/guide/screen#スマホの画面) — 幅の狭い画面では、テキストを読み取り専用で開き、「編集」で書き換えます
- 図の種類を、広く知られた名前（ブロック定義図・シーケンス図など）で呼ぶようにしました

[0.1.0-alpha.9 のリリースノート](/releases/v0.1.0-alpha.9)

# リリースノート

Modelith の各バージョンで変わったことです。いまは 0.1.0 に向けた beta 版です。0.1.0 までは、不具合の修正だけを行います。
ダウンロードやタグは [GitHub Releases](https://github.com/modelith/modelith/releases) にもあります。

## 最新：0.1.0-beta.5

図のエクスポートを「ファイル」メニューにまとめ、メニューの言葉をほかのツールに合わせた版です。機能は beta.1 のまま固定しています。

- 「ファイル」メニューの「エクスポート…」で、ファイル名と形式（SVG 画像・draw.io）を選んで、表示中の図をダウンロードできるようにしました。draw.io の形式は `.drawio` のファイルになり、draw.io でそのまま開けます
- 「図を保存…」を「新しい図を作成…」、「保存された図」を「作成した図」と呼ぶようにしました。図のタブの「＋」のメニューは「自動で描く図」と「作成した図」に分かれました
- 線を直角で描くか曲線で描くかを、「表示」メニューの「線の形」で選べるようにしました
- 画面の「書き出し」を「エクスポート」、「取り込み」を「インポート」に改めました

[0.1.0-beta.5 のリリースノート](/releases/v0.1.0-beta.5)

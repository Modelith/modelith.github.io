# リリースノート

Modelith の各バージョンで変わったことです。いまは 0.1.0 に向けた beta 版です。0.1.0 までは、不具合の修正だけを行います。
ダウンロードやタグは [GitHub Releases](https://github.com/modelith/modelith/releases) にもあります。

## 最新：0.1.0-beta.3

画面の言葉とキーボードでの操作を整えた版です。機能は beta.1 のまま固定しています。

- 保存や読み込みに失敗したときの理由を、ブラウザの英語の文ではなく、何が起きたかと次の操作を日本語で示すようになりました
- ダイアログ・図のタブ・モデルのツリーを、キーボードで操作できるようになりました。「ファイル」「ヘルプ」「＋」のメニューと draw.io 形式の書き出しの画面は、Esc キーで閉じられます
- 起動中は「読み込み中…」と表示し、15 秒たっても使えないときは再読み込みを案内します
- セキュリティの問題の報告先を用意しました

[0.1.0-beta.3 のリリースノート](/releases/v0.1.0-beta.3)

# リリースノート

Modelith の各バージョンで変わったことです。安定版はいま 0.1.0 の正式版の候補（rc）で、0.1.0 までは不具合の修正だけを行います。
開発中の 0.2.0 は、[プレビュー版](/guide/what-is-modelith#プレビュー版) としてプレリリース（alpha）を出しています。
ダウンロードやタグは [GitHub Releases](https://github.com/modelith/modelith/releases) にもあります。

## プレビュー版の最新：0.2.0-alpha.3

フォルダの中の複数のファイルを 1 つのモデルとして読み、すべてのファイルの問題を一覧できるようにした版です。[プレビュー版](https://modelith.github.io/modelith/preview/) で試せます。

- フォルダを開いているときは、ほかのファイルの定義を `import` や `Parts::Wheel` のような名前で使えるようにしました。問題一覧に、ほかのファイルの問題もファイルごとに並べます
- 線を選ぶと出るつまみで、曲がり角を足す・動かす・消す、線の端を付け替えることができるようにしました
- 「エクスポート…」で PNG・JPEG の画像に書き出し、範囲・倍率・背景を選べるようにしました。「画像をコピー」で、ほかのアプリに貼り付けられます
- 「知らせの重さ…」で、トレースの抜けやチェックの結果を、種類ごとに「エラー」「警告」「情報」「出さない」から選べるようにしました。問題一覧の行は、右クリックや Ctrl＋C でコピーできます
- 図のタブをファイルごとに持ち、フォルダの一覧で 1 回クリックしたファイルは仮に開くようにしました。他のアプリで変わったファイルを編集し始めたときは、ファイル名を示して尋ねます

[0.2.0-alpha.3 のリリースノート](/releases/v0.2.0-alpha.3)

## 安定版の最新：0.1.0-rc.1

0.1.0 の正式版の候補（rc）です。0.1.0-beta.6 から、機能と画面の変更はありません。1 週間ほど使っていただき、重大な不具合が見つからなければ、この内容で 0.1.0 を出します。

- 画面左上の札と「ヘルプ」に、正式版の候補（rc）であることを表示します

[0.1.0-rc.1 のリリースノート](/releases/v0.1.0-rc.1)

## 0.1.0-beta.6

トレースの抜けを、図を見たまま見つけて直せるようにした版です。機能は beta.1 のまま固定しています。

- 図のサブバーの「トレースの抜け N 件」を押すと、図のまま抜けのある要求を選んで図の中央に出し、何が足りないかと直し方を示すようにしました。その場で「関係を追加」を押して直せます
- 抜けが複数あるときは、案内の「1 / 3 件目」と「‹」「›」で順に移れます。抜けのある要素の箱には △ の印が付きます
- 要求から検証や部品へ線を引いたときも、「この検証で確かめる «verify»」「この部品で満たす «satisfy»」などを選べるようにしました（どちらの要素から線を引いても選べます）
- トレースの抜けの文で、要求の名前が 2 回出ていたのを直しました

[0.1.0-beta.6 のリリースノート](/releases/v0.1.0-beta.6)

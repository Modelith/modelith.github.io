# リリースノート

Modelith の各バージョンで変わったことです。いまは 0.1.0 に向けた beta 版です。0.1.0 までは、不具合の修正だけを行います。
ダウンロードやタグは [GitHub Releases](https://github.com/modelith/modelith/releases) にもあります。

## 最新：0.1.0-beta.1

0.1.0 に向けた最初の beta 版です。開き直したときに、前回の続きから始めるようになりました。

- 前回開いていたフォルダとファイル、表示していたファイル、図のタブが戻ります。→ [前回の続きから始める](/guide/files#前回の続きから始める)
- フォルダを読み直すのにブラウザの許可が要るときは、「前回の続きを開く」を押して許可します
- これまでどおりサンプルから始めたいときは、「ファイル」メニューの「起動時にサンプルを開く」をオンにします
- この版で 0.1.0 の機能を固定しました。0.1.0 までは、不具合の修正だけを行います

[0.1.0-beta.1 のリリースノート](/releases/v0.1.0-beta.1)

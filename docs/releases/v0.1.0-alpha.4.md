# Modelith 0.1.0-alpha.4

保存した図の中で、モデルの入れ物（package）を枠で囲んで描けるようになりました。あわせて、大きなモデルでの動きを軽くし、名前の変更と削除の不具合を直しました。

## 新しい機能

- 図の中で package を枠で囲む：保存した図のテキストに package そのものを書き入れる（例：`expose P::Drive;`）と、その package を名前付きの枠で描き、中の要素を枠の中に並べます。どの要素がどの package に入っているかが、図で分かります。package の中の package は、枠の中の枠になります

## 改善

- 動きの軽さ：テキストの読み取りと図の操作を、画面とは別の処理で行うようにしました。大きなモデルでも、入力や図の操作が止まりにくくなりました。図の操作を反映する前にテキストが書き換わったときは、その操作をやめてお知らせします

## 不具合の修正

- 名前の変更：部品の名前を変えると、別の定義にある同じ名前まで書き換えていました。部品を持つ定義の中だけを書き換えるようになりました。文字列の中の文字も変えなくなりました
- まとめて削除：複数の要素を選んで削除すると、ファイルの他の部分の空行まで詰めていました。選んだ要素の行だけを消すようになりました。選んだ要素の中にある要素も一緒に選んでいても、正しく消えます

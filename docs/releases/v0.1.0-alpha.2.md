# Modelith 0.1.0-alpha.2

図の配置の保存方法を改め、図を名前を付けて保存できるようにしました。

## 新しい機能

- 図を保存：表示中の図を、名前を付けて保存できます。保存した図には、パレットやツリーから要素を入れたり、右クリックで外したりできます。図から外しても、モデルの要素は消えません
- 保存された図の表示：保存した図は、図のタブの「＋」から開けます。SysML v2 標準の view として書かれた図も、ここから開けます
- 新しいファイルの案内：モデルの入れ物（package）が無いファイルで要素を置こうとすると、入れ物を作るよう案内します

## 改善

- 配置を別のファイルに保存：図の配置（要素の位置）は、モデルのファイル（例：model.sysml）には書き込まず、同じ名前の別のファイル（model.layout.json）に保存します
- フォルダを開いていれば、配置もそのまま保存されます
- ファイルを 1 つだけ開いて配置を変えたときは「配置は未保存」と表示し、保存するときにフォルダを開くよう案内します
- Safari・Firefox では、モデルと配置の 2 つのファイルをダウンロードします。開くときに 2 つを一緒に選ぶと、配置も戻ります
- 画面の言葉：SysML v2 の書き方を知らなくても分かる言葉に見直しました
- ヘルプ：画面右上の「?」を「ヘルプ」にしました

## 0.1.0-alpha.1 をお使いの方へ

- 以前の版はモデルのファイルの中に図の配置を書き込んでいました。そのファイルを開くと、配置を別のファイルに移すかを一度だけ尋ねます。移さなくても、そのまま使えます。

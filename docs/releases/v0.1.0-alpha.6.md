# Modelith 0.1.0-alpha.6

画面に機能を追加するプラグイン（TypeScript）を使えるようになりました。プラグインは、自分のブラウザにだけ追加することもでき、フォルダを開けない Firefox や Safari でも使えます。

## 新しい機能

- 画面に機能を追加するプラグイン：コマンドの実行、モデルのチェック（結果は問題一覧に表示）、テキストの変更ができるプラグイン（TypeScript）を、「ファイル → プラグイン…」から追加できます。プラグインはアプリから切り離された場所で動き、追加するときに示した権限だけを使えます。コマンドは「ファイル」メニューの「プラグインのコマンド」から実行します。プラグインによる変更は、1 回の「元に戻す」で取り消せます。作り方は[プラグインの作り方](https://github.com/modelith/modelith/blob/dev/docs/reference/script-plugins.md)をご覧ください
- 実行の許可：プログラムを含むプラグインは、初めて動かす前に、名前・作者・バージョン・使う権限を示して、実行してよいかを尋ねます。インターネットなど外部と通信できるプラグインは、そのことをはっきり示します。使う権限が増えたとき、または外部と通信できるプラグインのバージョンかファイルが変わったときは、もう一度尋ねます
- このブラウザに追加：プラグインを追加するとき、追加先を「このプロジェクト」（チームで共有）と「このブラウザ」（自分だけ）から選べます。このブラウザに追加したプラグインは、どのプロジェクトでも、フォルダを開いていなくても使えます。フォルダを開けないブラウザ（Firefox・Safari）でも、プラグインを使えるようになりました
- プラグインで読み込む・書き出す：「ファイル」メニューの「プラグインで読み込む」「プラグインで書き出す」から、プラグインが対応する形式のファイルを読み込んだり、モデルを書き出したりできます。読み込んだ結果は新しい無題のファイルとして開き、書き出した結果はダウンロードとして受け取ります
- プラグイン用の保存場所：保存の権限を持つプラグインは、このブラウザにデータを保存できます。プラグインを削除するときに、保存したデータを残すか消すかを選べます

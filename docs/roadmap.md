# ロードマップ

Modelith のこれからの予定です。予定は、テストユーザーの声に合わせて入れ替えることがあります。
必要な機能や書き方があれば、[GitHub Issues](https://github.com/modelith/modelith/issues/new/choose) でお知らせください。利用者の声が無い機能は、先回りして作らない方針です。

開発者向けの詳しい計画は、modelith リポジトリの [リリース計画](https://github.com/modelith/modelith/blob/dev/docs/development/release-plan.md) にあります。

## 0.2.0

alpha・beta・rc の順にプレリリースを出し、0.2.0 の正式版の候補（rc）を出す予定です。プレリリースは [プレビュー版](/guide/what-is-modelith#プレビュー版) で試せます。

| 内容 | 状況 |
| --- | --- |
| 図を作る：「新しい図を作成…」で名前と図の種類を選び、空の図からも作れる。サイドバーに作成した図を並べ、開く・名前の変更・削除ができる | 0.2.0-alpha.2 で公開済み（プレビュー版） |
| 画面で編集できることを増やす：要求の文章、属性とその値、日本語の名前を、テキストを書かずに編集できる | 0.2.0-alpha.2 で公開済み（プレビュー版） |
| よく使う 4 つの図の不足を埋める：要求図（目的・検証の線・制約）、ブロック定義図（アクション・アイテム・状態の使用、定義の中の特性どうしの線）、内部ブロック図（外枠のポートへの線、入れ子の部品のポートを図から作る）、アクティビティ図（パラメータとその間のフロー、区画（スイムレーン）） | 0.2.0-alpha.2・alpha.3 で公開済み（プレビュー版） |
| 複数のファイルにまたがるモデル：フォルダの中のファイルを 1 つのモデルとして読み、`import` やほかのファイルの名前を使える。すべてのファイルの問題を一覧する | 0.2.0-alpha.3 で公開済み（プレビュー版） |
| 線の調整：線の曲がり角を足す・動かす・消す、線の端を付け替える | 0.2.0-alpha.3 で公開済み（プレビュー版） |
| エクスポートの強化：PNG・JPEG、範囲・倍率・背景、画像のコピー | 0.2.0-alpha.3 で公開済み（プレビュー版） |
| 知らせの重さを選べる：トレースの抜けやチェックの結果を、種類ごとに「エラー」「警告」「情報」「出さない」から選ぶ。問題一覧の行をコピーできる | 0.2.0-alpha.3 で公開済み（プレビュー版） |
| ファイルの扱いの見直し（0.1.0-rc.1 へのご意見から）：図のタブをファイルごとに持つ、1 回クリックでファイルを仮に開く、他のアプリでの変更をファイル名とともに知らせる | 0.2.0-alpha.3 で公開済み（プレビュー版） |
| プロジェクトの一覧：開いたプロジェクトの一覧・切り替え・フォルダを閉じる | 次の予定 |

## SysML v2 の書き方への対応

| バージョン | 内容 |
| --- | --- |
| 0.2.0 または 0.3.0 | パッケージやファイルをまたぐ名前（進み具合を見て決めます）：`import`、ほかのファイルの `alias`・修飾名・可視性、`expose` で `import` を通した名前。複数のファイルにまたがるモデル |
| 0.3.0 以降 | 式の計算と単位（ビューの `filter` でメタデータの値を比べる式を含む）、KerML の文法、標準ライブラリの同梱、ジオメトリビュー・グリッドビュー・ブラウザビュー、表や文字の形の図、シーケンス図の分岐や繰り返しの枠と入れ子、モデル交換の形式（`.kpar`） |

いまの対応状況は [対応している書き方](/sysml/support) を見てください。

## 0.1.0 より先

0.1.0 の先は、コマンドラインのツール（CLI）・AI エージェントやエディタとの連携（MCP・LSP）・プラグイン・サーバへと広げていく予定です。

保存と共有は、必要になったら次の順に広げます。どの段階も、いまは着手していません。

| 段階 | 内容 | サーバ |
| --- | --- | --- |
| 1. クラウド保存 | Google ドライブのファイルを、手元のファイルと同じ操作で開いて保存する | 不要 |
| 2. チームで共有 | ドライブの共有フォルダで、チームが同じモデルを開く。同時に編集したときの競合を扱う。Git・GitHub での共有も検討する | 不要 |
| 3. Web サービス | アカウント、チームの管理、必要なら有料プラン | 必要 |

デスクトップアプリ（インストールして使う版）が必要かどうかは、beta の前後に判断します。

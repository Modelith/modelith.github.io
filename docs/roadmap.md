# ロードマップ

Modelith のこれからの予定です。予定は、テストユーザーの声に合わせて入れ替えることがあります。
必要な機能や書き方があれば、[GitHub Issues](https://github.com/modelith/modelith/issues/new/choose) でお知らせください。利用者の声が無い機能は、先回りして作らない方針です。

開発者向けの詳しい計画は、modelith リポジトリの [リリース計画](https://github.com/modelith/modelith/blob/dev/docs/development/release-plan.md) にあります。

## SysML v2 の書き方への対応

| バージョン | 内容 |
| --- | --- |
| 0.2.0 | パッケージやファイルをまたぐ名前：`import`、ほかのファイルの `alias`・修飾名・可視性、`expose` で `import` を通した名前。複数のファイルにまたがるモデル |
| 0.3.0 以降 | 式の計算と単位（ビューの `filter` でメタデータの値を比べる式を含む）、KerML の文法、標準ライブラリの同梱、ジオメトリビュー・グリッドビュー・ブラウザビュー、表や文字の形の図、シーケンス図の分岐や繰り返しの枠と入れ子、モデル交換の形式（`.kpar`） |

いまの対応状況は [対応している書き方](/sysml/support) を見てください。

## 0.1.0 より先

0.1.0 の先は、コマンドラインのツール（CLI）・AI エージェントやエディタとの連携（MCP・LSP）・プラグイン・サーバへと広げていく予定です。

保存と共有は、必要になったら次の順に広げます。どの段階も、いまは着手していません。

| 段階 | 内容 | サーバ |
| --- | --- | --- |
| 1. クラウド保存 | Google ドライブのファイルを、手元のファイルと同じ操作で開いて保存する | 不要 |
| 2. チームで共有 | ドライブの共有フォルダで、チームが同じモデルを開く。同時に編集したときの競合を扱う。Git・GitHub での共有も検討する | 不要 |
| 3. Web サービス | アカウント、チームの管理、必要なら有料プラン | 必要 |

デスクトップアプリ（インストールして使う版）が必要かどうかは、beta の前後に判断します。

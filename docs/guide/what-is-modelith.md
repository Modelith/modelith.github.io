# Modelith とは

Modelith は、システムエンジニア・学生・研究者のための **SysML v2 のモデリングエディタ** です。
テキストで書いたモデルがすぐ図になり、図で足した要素や関係はテキストに書き戻されます。ブラウザで開くだけで使えます。

[ブラウザで試す →](https://modelith.github.io/modelith/)

![Modelith の画面。左にモデルのツリー、中央にロボット掃除機のブロック定義図、右に SysML v2 のテキスト](/images/overview.jpg)

## できること

- **書いても、描いても、同じモデル** — テキストを打てば図・ツリー・問題一覧に反映します。図で要素や関係を足すと、テキストが書き換わります。モデルの正本はいつもテキストです。
- **目的に合わせた図** — トレーサビリティ・ブロック定義図・制御ループ・内部ブロック図・振る舞い・シーケンス図・アクティビティ図・すべて、の 8 つの図と、状態遷移図があります。見たい要素だけを集めた図を、名前を付けて保存することもできます。→ [図の種類と開き方](/diagrams/)
- **要求の抜けに気づける** — 利用者要求から方式設計・検証までのつながりをたどり、導出・充足・検証の抜けを知らせます。→ [トレーサビリティとフェーズ](/diagrams/traceability)
- **書き方を知らなくても読める** — テキストの語（`part def`・`satisfy` などのキーワードや、図の種類の名前）にマウスを乗せると、その意味を表示します。画面の言葉も、SysML v2 の書き方を知らない人に分かる言葉にしています。
- **手元のフォルダをそのまま開ける** — VS Code のようにフォルダを開いて、中のファイルを編集・上書き保存できます。→ [ファイルとフォルダ](/guide/files)
- **チームの決まりを確かめる** — チェックルールのプラグインで、モデルがチームの決まりに沿っているかを確かめられます。→ [チェックルールとプラグイン](/guide/plugins)
- **持ち出せる** — 表示中の図を SVG で保存したり、draw.io 形式で書き出したりできます。→ [図の操作と書き出し](/diagrams/editing)

## 動作環境

インストールもアカウントも不要です。パソコンのブラウザで [https://modelith.github.io/modelith/](https://modelith.github.io/modelith/) を開きます。
初めて開くと、サンプルのモデル（電気ケトル）が表示されます。次からは、前回の続きから始まります。

| ブラウザ | できること |
| --- | --- |
| Chrome・Edge | フォルダを開いて、ファイルを直接編集・上書き保存できます。フォルダを [プロジェクト](/guide/files#プロジェクト) にして、チェックルールをチームで共有できます |
| Safari・Firefox | ファイルの読み込みと、ダウンロードでの保存ができます（フォルダは開けません） |
| スマホなど幅の狭い画面 | モデルを見て確かめるための画面になります。テキストは読み取り専用で開き、書き換えるときは「編集」を押します → [スマホの画面](/guide/screen#スマホの画面) |

::: tip
開いてから使えるようになるまで「読み込み中…」と表示します。15 秒たっても使えないときは、再読み込みを案内します。
WebAssembly を使えない古いブラウザでは起動できません。「Modelith を起動できませんでした」と表示されたら、ページを再読み込みするか、新しいブラウザ（Chrome・Edge・Firefox・Safari の最新版）で開いてください。
:::

## データの扱い

- **モデルを外部に送りません。** モデルは、手元のファイルか、このブラウザの中にだけ置かれます。アクセス解析も使いません。フォントなども同梱していて、外部の CDN と通信しません。
- **保存先の無いファイル（新しいファイルやサンプル）は、このブラウザの下書きにだけ残ります。** ブラウザのデータを消すと失われます。手元に残すには「ファイル → 名前を付けて保存…」で保存してください。
- **モデルはただのテキストファイルです。** SysML v2 のテキスト（`.sysml`）として保存するので、Git で差分を追ったり、ほかのツールで開いたりできます。図の配置（要素の位置）は、モデルとは別のファイル（`.layout.json`）に保存します。
- プラグインを追加したときは、プラグインが使う権限を、実行してよいかを尋ねる画面で示します。外部と通信できるプラグインは、そのことをはっきり示します。→ [プラグインの許可](/guide/plugins#実行の許可)

## 開発状況

いまは **0.1.0 に向けた beta 版** です。機能を固定し、0.1.0 までは不具合の修正だけを行います。
このマニュアルは **0.1.0-beta.4** に合わせて書いています。操作方法や保存形式は、予告なく変わることがあります。

- 画面左上のメニューバーの「ヘルプ」で、動いているバージョン・ソースコード・ライセンス・このバージョンのテスト結果を確かめられます。
- 各バージョンの変更点は [リリースノート](/releases/)、この先の予定は [ロードマップ](/roadmap) をご覧ください。
- 使ってみた感想や「こんな図がほしい」は、[GitHub Issues](https://github.com/modelith/modelith/issues/new/choose) にお寄せください（画面の「ヘルプ → 不具合・要望を送る（GitHub）」からも開けます）。

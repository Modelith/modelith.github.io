# はじめての図

Modelith は、3 つのどの使い方でも同じモデルを作れます。

| 使い方 | こんな人に | 読むところ |
| --- | --- | --- |
| **図だけで描く** | SysML v2 の書き方を知らない人。パレットで箱を置き、線を引いて作ります | このページ |
| **テキストだけで書く** | 書き方を知っている人、Git で差分を追いたい人。テキストを打つと図が描かれます | [テキストで書く・行き来する](/guide/text-and-diagram#テキストだけで書く) |
| **両方を行き来する** | 図で足して、細かいところはテキストで直す、のように使い分けたい人 | [テキストで書く・行き来する](/guide/text-and-diagram#図とテキストを行き来する) |

どれを選んでも、できあがるのは同じ SysML v2 のテキストのファイル（`.sysml`）です。途中で使い方を変えてもかまいません。

このページでは、自転車のライトを例に、**図の操作だけで** 要求と部品を置き、関係を引き、ファイルに保存するまでを 10 分ほどで試します。
キーボードで打つのは、要素の名前とファイル名だけです。ここでは Chrome か Edge を使います（Safari・Firefox の違いは最後に書きます）。

::: tip テキストは読むだけで大丈夫です
画面の右の欄には、図の操作に合わせて SysML v2 のテキストが自動で書き足されます。このチュートリアルでは、書き足された結果を見るだけで、テキストを書く必要はありません。
:::

## 1. Modelith を開いて、新しいファイルを作る

ブラウザで [https://modelith.github.io/modelith/](https://modelith.github.io/modelith/) を開きます。初めて開くと、サンプルのモデル（電気ケトル）が表示されます。

画面左上のメニューバーの「ファイル」を押して、「新しいファイル」を選びます。
空のファイル `untitled-1.sysml` が開き、左のエクスプローラーの「開いているファイル」に加わります。

続けて、図のタブの右の「＋」を押し、「すべて」を選びます。「すべて」は、どの種類の要素も置ける図です。

![新しいファイルを作り、「すべて」の図を開いたところ。図とテキストは空](/images/tutorial-1-new-file.jpg)

::: tip まだ保存先はありません
新しいファイルには保存先がありません。保存するまでは、このブラウザの中に下書きとして自動で残ります（ブラウザを閉じても、次に開いたときに戻ります）。保存は手順 7 で行います。
:::

## 2. 要求を置く

まず「夜道を十分に照らせること」という要求を置きます。

1. 図の上の道具の並び（パレット）の「要求」を押します。
2. 図の上の空いているところをクリックします。
3. 「パッケージを作成します」の画面が出ます。要素はパッケージ（モデルの要素をまとめる入れ物）の中に置くためです。パッケージ名に `BicycleLight` と入れて、「作成して配置」を押します。

![パッケージを作成しますの画面。パッケージ名に BicycleLight](/images/tutorial-2-package.jpg)

要求の箱が置かれ、図の下に名前の入力欄が出ます。`BrightEnough` と入れて Enter を押します（「変更する」を押しても同じです）。

![要求 BrightEnough を置いたところ。テキストに package と requirement def が書き足された](/images/tutorial-3-requirement.jpg)

右のテキストを見ると、次の内容が自動で書き足されています。パッケージは図には出ず、モデルのツリーの一番上に出ます。

```sysml
package BicycleLight {
    requirement def BrightEnough {
        doc /* ここに要求文を書く */
    }
}
```

::: info 名前の付け方
要素の名前は、英字か `_` で始め、英字・数字・`_` だけで付けます（`BrightEnough`・`battery_2` など）。日本語の説明は、要求の文章やメモに書きます。
:::

## 3. 部品定義を置く

同じようにして、ライトとその部品を置きます。

1. パレットの「部品定義」を押し、図の上をクリックして、名前を `Light` にします。
2. もう一度「部品定義」で `Battery`、さらに `Led` を置きます。

テキストには、`part def Light { }` のような行が 3 つ書き足されます。部品定義は、部品の型（設計図）です。

## 4. 部品を持たせる

ライト（Light）が電池（Battery）と LED（Led）を部品として持つ、という関係を引きます。

1. Light の箱をクリックして選びます。図の下に、選んだ要素の操作（インスペクタ）が出ます。
2. インスペクタの「関係を追加」を押します。「接続先の要素をタップしてください」と出ます。
3. Battery の箱をクリックします。インスペクタに、この 2 つの間に追加できる関係が並びます。
4. 「部品として持つ」を押します。

![Light から Battery への関係を選ぶところ。「部品として持つ」が選べる](/images/tutorial-4-parts.jpg)

Light から Battery へ線が引かれ、テキストの Light の中に `part battery : Battery;` が書き足されます。部品の名前（`battery`）は、型の名前から自動で付きます。
同じようにして、Light に Led も持たせます。

選んだ要素の縁に出る「＋」から、相手の要素までドラッグしても、同じように関係を選べます。

## 5. 要求を満たす関係を引く

Light が要求 BrightEnough を満たす、という関係を引きます。
Light を選んで「関係を追加」を押し、BrightEnough をクリックして、「要求を満たす «satisfy»」を押します。

図に «satisfy» の破線の矢印が引かれ、テキストに次の 1 行が書き足されます。書き足した行は、しばらく色が付きます。

```sysml
    satisfy BrightEnough by Light;
```

![図に «satisfy» の線と部品の線が引かれ、テキストに satisfy の行が足された](/images/tutorial-5-satisfy.jpg)

図での操作は、すべてテキストの書き換えになります。操作を取り消すときは、画面左上の「元に戻す」ボタン（左向きに曲がった矢印。Ctrl+Z）を押します。

::: tip 図の配置
図の箱はドラッグで動かせます。動かした位置は、モデルとは別の「図の配置」として保存されます（手順 7）。自動で並べ直すときは「整列」を押します。
:::

::: info 要求の文章はテキストで書きます
要求の箱の「ここに要求文を書く」は、要求の文章（説明）の場所です。**文章の中身は、図からは書き換えられません。この操作はテキストで行います。**
テキストの `/* ここに要求文を書く */` の中を、`/* 夜道で 10 m 先まで照らせる */` のように書き換えると、箱の中の文章も変わります。
:::

## 6. ほかの図で見る

同じモデルを、別の図で開けます。図のタブの右の「＋」から選びます。

- **内部ブロック図** — Light の中に、battery と led の部品が並びます（タブは `ibd Light`）。
  battery を右クリックして「関係を追加…」を選び、led をクリックして「信号・物理量を流す（flow）」を押すと、電池から LED への流れの矢印が引かれ、テキストに `flow from battery to led;` が書き足されます。
- **トレーサビリティ** — 要求 BrightEnough と、それを満たす Light が並びます。

![内部ブロック図。Light の中の battery から led へ流れの矢印](/images/tutorial-6-ibd.jpg)

図の種類は [図の種類と開き方](/diagrams/) をご覧ください。

## 7. 保存する

「ファイル → 保存」（Ctrl+S）を押します。新しいファイルなので、保存先を決めます。

1. フォルダを選ぶ画面が出ます。保存先のフォルダを選び、ブラウザの確認でファイルの編集を許可します。
2. 「名前を付けて保存」の画面で、ファイル名（例：`bicycle-light.sysml`）を入れて「保存」を押します。

![名前を付けて保存の画面。フォルダ「my-models」に保存する](/images/tutorial-7-save.jpg)

フォルダには、モデルのファイル `bicycle-light.sysml` と、図の配置を入れたファイル `bicycle-light.layout.json` の 2 つができます。
エクスプローラーにフォルダの中身が出て、以後は Ctrl+S で上書き保存できます。

![エクスプローラーに、保存したファイルが出ている](/images/tutorial-8-saved.jpg)

::: info Safari・Firefox の場合
フォルダを開けないため、保存は **ダウンロード** になります。モデル（`.sysml`）と図の配置（`.layout.json`）の 2 つのファイルがダウンロードされます。
続きを編集するときは「ファイル → ファイルを開く…」で、2 つのファイルを一緒に選ぶと、図の配置も戻ります。→ [ファイルとフォルダ](/guide/files)
:::

## テキストで書くこともできます

ここまで図で作ったモデルは、テキストで書くと次のとおりです。右の欄に直接書いても、同じ図になります（図で置いた部品定義は `part def Battery {
}` のように書かれますが、中身の無い `part def Battery;` と同じ意味です）。

```sysml
package BicycleLight {
    requirement def BrightEnough {
        doc /* 夜道で 10 m 先まで照らせる */
    }
    part def Light {
        part battery : Battery;
        part led : Led;
        flow from battery to led;
    }
    part def Battery;
    part def Led;
    satisfy BrightEnough by Light;
}
```

テキストから始める方法と、図とテキストを行き来する使い方は [テキストで書く・行き来する](/guide/text-and-diagram) を、書き方の基本は [SysML v2 の書き方入門](/sysml/basics) をご覧ください。

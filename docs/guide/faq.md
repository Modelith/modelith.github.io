# よくある質問・困ったとき

## 保存できない

- **Safari・Firefox を使っている** — フォルダを開いて上書き保存できるのは Chrome と Edge です。Safari・Firefox では、保存はダウンロードになります。ダウンロードしたファイルを、次に「ファイルを開く…」で開いて続きを編集します。→ [ブラウザによる違い](/guide/files#ブラウザによる違い)
- **新しいファイルやサンプルを編集している** — 保存先が無いので、内容はこのブラウザの下書きにだけ残っています。「ファイル → 名前を付けて保存…」で保存してください。
- **「配置は未保存」と出る** — ファイルを 1 つだけ開いたときは、図の配置（要素の位置）を保存する場所がありません。保存するときの案内に従って、そのファイルが入っているフォルダを開いてください。モデルのテキストは保存されています。
- **「ファイルが他で変更されています」と出る** — 開いた後に、ほかのアプリでファイルが変わりました。「ファイルの内容を読み込む（自分の変更を捨てる）」か「自分の内容で上書きする」を選びます。
- **「保存できませんでした：…」と出る** — 「：」の後に理由が出ます。ブラウザの確認でファイルの編集を許可しなかったときは、フォルダを開き直して許可してください。

## フォルダが開けない

- 「フォルダを開く」は Chrome と Edge だけで使えます。Safari・Firefox では、エクスプローラーに「このブラウザではフォルダを開けません」と出ます。
- ブラウザの確認で許可しなかったときは、もう一度「フォルダを開く」を押して許可してください。
- システムのフォルダなど、ブラウザが開くことを許さないフォルダがあります。ドキュメントなどの下にモデル用のフォルダを作って開いてください。
- エクスプローラーには `.sysml`・`.kerml` のファイルだけが並びます。「モデルのファイル（.sysml）がありません。」と出るときは、そのフォルダにモデルのファイルがありません。

## スマホで編集したい

スマホなど幅の狭い画面は、モデルを見て確かめるための画面です。テキストは読み取り専用で開きます。
書き換えるときは、テキストの上の「編集」を押します。もう一度押すと、読み取り専用に戻ります。
スマホのブラウザではフォルダを開けないので、保存はダウンロードになります。→ [スマホの画面](/guide/screen#スマホの画面)

## 図が崩れた・見づらい

- サブバーの「整列」で、図を自動で並べ直せます。
- 図が画面からはみ出しているときは、右上の「全体」を押します。
- 線が重なって見づらいときは、「線：直角」と「線：曲線」を切り替えてみてください。
- 要素が多すぎるときは、見たい要素だけを集めた [保存された図](/diagrams/saved-views) を作ります。フェーズで絞り込むこともできます。
- 配置ファイル（`.layout.json`）を消すと、すべての図が自動の配置に戻ります（モデルは変わりません）。

## 図に要素が出ない

- 図の種類ごとに、出る要素が決まっています。たとえば部品定義はトレーサビリティには（要求を満たしていなければ）出ません。→ [図の種類と開き方](/diagrams/)
- テキストで要素を選んだときに「「X」は「…」には出ていません」と出るのは、その図に出ない要素だからです。
- 問題一覧にエラーや「まだ扱えない」が出ていないか確かめてください。まだ対応していない書き方は、図に出ません。→ [対応している書き方](/sysml/support)
- `import` やほかのファイルの要素は、まだ読めません（0.2.0 で対応する予定です）。

## 書いたモデルはどこにありますか

- フォルダやファイルを開いて保存したモデルは、そのファイルにあります。
- 保存先の無いファイル（新しいファイル・サンプル）は、このブラウザの中の下書きにあります。別のブラウザや別のパソコンからは見えません。
- Modelith はモデルを外部に送りません。→ [データの扱い](/guide/what-is-modelith#データの扱い)

## 不具合の報告・要望

[GitHub Issues](https://github.com/modelith/modelith/issues/new/choose) にお寄せください。画面の「ヘルプ → 不具合・要望を送る（GitHub）」からも開けます。
報告には、次の内容を添えていただけると助かります。

- 使っている Modelith のバージョン（「ヘルプ」の下のほうに出ます。例：`0.1.0-beta.2`）
- ブラウザと OS（例：Chrome 141・Windows 11）
- 操作の手順と、起きたこと・期待したこと
- 再現できる小さなモデル（会社や個人の秘密を含まないもの）

「ヘルプ → このバージョンのテスト結果」で、動いているバージョンでどの要求のテストが通っているかを確かめられます。

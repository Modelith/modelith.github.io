# 画面の見方

Modelith の画面は、左から **サイドバー（エクスプローラー・モデル）**・**図**・**テキスト** の 3 つに分かれています。
どの部分で操作しても、同じモデル（テキスト）が書き換わり、ほかの部分にすぐ反映します。

![画面の各部分に番号を付けた図](/images/screen-map.jpg)

| 番号 | 部分 | 内容 |
| --- | --- | --- |
| 1 | 同期の表示 | テキストと図の同期の状態 |
| 2 | メニューバー | ファイル・編集・表示・図・プラグイン・ヘルプのメニュー |
| 3 | サイドバー | エクスプローラー（ファイル）とモデル（ツリー） |
| 4 | 図のタブ | 開いている図。「＋」で図を開く |
| 5 | パレット | 図に要素を置く道具 |
| 6 | サブバー | 図の対象・フェーズの絞り込み・トレースの抜け・新しい図を作成・線・整列 |
| 7 | 図 | 要素と関係の図 |
| 8 | インスペクタ | 選んだ要素の情報と操作 |
| 9 | 全体図 | 図の全体と、いま見ている範囲 |
| 10 | テキスト | SysML v2 のテキスト（モデルの正本） |
| 11 | 問題一覧 | エラー・警告・トレースの抜けなど |

## ヘッダー

画面の一番上の帯です。左から、ロゴ・メニューバー・元に戻す／やり直すのボタン、右の端に同期の表示と rc の札が並びます。

- **メニューバー** — 「ファイル」「編集」「表示」「図」「プラグイン」「ヘルプ」のメニューです。中身は次の [メニューバー](#メニューバー) を見てください。
- **元に戻す・やり直す**（曲がった矢印のボタン） — 元に戻す（Ctrl+Z）・やり直す（Ctrl+Shift+Z）。履歴はファイルごとに持ちます。
- **同期の表示** — テキストと図の同期の状態です。「同期済み」、入力中は「編集中…」、問題があるときは「同期済み（問題 N 件）」と出ます。
- **rc** — 0.1.0 の正式版の候補（rc）であることを示します。

## メニューバー

画面の左上、ロゴの隣のメニューの並びです。見出しを押すとメニューが開き、項目を押すと実行して閉じます。

| メニュー | 項目 |
| --- | --- |
| ファイル | 新しいファイル・ファイルを開く…・フォルダを開く…・保存・名前を付けて保存…・自動保存・エクスポート…・サンプルを開く・起動時にサンプルを開く → [ファイルとフォルダ](/guide/files)・[エクスポートする](/diagrams/editing#エクスポートする) |
| 編集 | 元に戻す・やり直す・すべて選択（図の要素をすべて選ぶ） |
| 表示 | ツリー・テキスト（サイドバーとテキストの表示・非表示の切り替え）・拡大・縮小・全体を表示・全体図・線の形（直角・曲線） |
| 図 | 新しい図を作成…・整列 → [新しい図を作成する](/diagrams/create-diagram)・[図の操作とエクスポート](/diagrams/editing) |
| プラグイン | プラグインの一覧…と、動いているプラグインが足したコマンド・インポート・エクスポート → [チェックルールとプラグイン](/guide/plugins) |
| ヘルプ | 不具合・要望を送る（GitHub）・このバージョンのテスト結果・ソースコード・ライセンス・同梱ソフトウェアのライセンスへのリンクと、バージョン・著作権・商標の表示 |

- メニューを 1 つ開いている間は、マウスを隣の見出しに乗せると、そのメニューに切り替わります。
- キーボードでは、メニューを開いている間、**←・→** で隣のメニューへ（両端では反対の端へ回ります）、**↑・↓** で項目を移ります。**Esc** でメニューを閉じます。
- 「表示」の「ツリー」「テキスト」を押すと、サイドバーやテキストを隠して、図を広く使えます。もう一度押すと戻ります。
- 幅の狭い画面では、メニューは左上の「☰」の 1 つにまとまります → [スマホの画面](#スマホの画面)

## サイドバー

左の欄です。上の「エクスプローラー」と「モデル」で切り替えます。区切りの線をドラッグすると幅を変えられます。

### エクスプローラー

開いているファイルと、開いたフォルダの中のファイルを一覧します。

- **開いているファイル** — いま開いているファイルです。押すと切り替わります。「＋」で新しいファイル、「×」で閉じます。
  - `●` は未保存の変更があること、`⚠` は開いた後にほかのアプリでファイルが変わったこと、「配置は未保存」は図の配置を保存する場所が無いことを示します。
- **フォルダ** — 「フォルダを開く」で開いたフォルダの、`.sysml`・`.kerml` のファイルをツリーで一覧します。「＋」でこのフォルダに新しいファイル、「↻」で一覧を更新します。「プロジェクトにする」については [プロジェクト](/guide/files#プロジェクト) を見てください。

![フォルダを開いたエクスプローラー](/images/explorer-folder.jpg)

### モデル（ツリー）

開いているファイルのモデルの要素を、入れ子のツリーで一覧します。上の欄に名前を入れると、名前で絞り込めます。

- 行を押すと、その要素を図とテキストで選びます。
- 行にマウスを乗せると出る「開く」で、その要素に合った図を開きます（ダブルクリック・Enter でも開きます）。たとえば部品を持つ部品定義は内部ブロック図、アクション定義はアクティビティ図、状態定義は状態遷移図で開きます。
- キーボードでは、Tab キーでツリーに入り、上下の矢印キーで行を移ります。スペースキーでその要素を選び、Enter で図を開きます。
- 右クリックで「テキストで見る」・「この図で選択」・「〜で開く」・「名前を変更」・「削除」などを選べます。
- 作成した図を表示しているときは、「追加」やドラッグで、要素をその図に入れられます。→ [新しい図を作成する](/diagrams/create-diagram)

![ツリーの行の「開く」ボタン](/images/tree-open-button.jpg)

## 図

中央の欄です。

### タブと＋メニュー

開いている図をタブで切り替えます。「×」で閉じます（タブが 2 つ以上のとき）。開いているタブと表示位置は、このブラウザに記憶されます。
キーボードでは、Tab キーで図のタブに移り、左右の矢印キーで隣の図、Home・End で最初・最後の図に切り替えます。
タブの右の「＋」を押すと、「自動で描く図」（組み込みの図）と「作成した図」の 2 つの見出しに分けて、図の一覧が出ます。項目にマウスを乗せると、SysML v2 の標準のビューの名前が出ます。

![＋メニュー。「自動で描く図」の 8 つの図と、「作成した図」](/images/plus-menu.jpg)

### パレット

図の上の道具の並びです。

- **選択** — ふだんの状態です。何も無いところをドラッグすると範囲選択します（Esc で選択に戻ります）。
- **移動** — ドラッグで表示範囲を動かします（中ボタンのドラッグ・スペースキーを押しながらのドラッグでも動かせます）。
- **要素の道具**（部品定義・要求など） — 押してから図の上をクリックすると、その要素を置きます。テキストに宣言が書き足されます。置ける要素は図の種類で変わります。
- 内部ブロック図では「部品を置く…」、シーケンス図では「ライフラインを追加…」と「シナリオ」が出ます。

パッケージの無いファイルで要素を置こうとすると、パッケージを作るよう案内します（名前を決めると、パッケージを作ってその中に置きます）。

### サブバー

パレットの右（狭いときは下）の並びです。図の種類によって中身が変わります。

- **対象の選択** — 内部ブロック図の「対象ブロック」、シーケンス図の「シナリオ」、アクティビティ図の「アクション定義」、状態遷移図の「状態定義」です。
- **フェーズ** — フェーズで図を絞り込みます。フェーズがまだ無いときは「フェーズ管理を始める」が出ます。→ [トレーサビリティとフェーズ](/diagrams/traceability)
- **トレースの抜け N 件** — 押すと、図のまま最初の抜けのある要求を選んで中央に出し、インスペクタに何が足りないかと直し方を示します。→ [トレースの抜け](/diagrams/traceability#トレースの抜け)
- **新しい図を作成** — 表示中の図の要素と配置のまま、名前の付いた新しい図を作成します。→ [新しい図を作成する](/diagrams/create-diagram)
- **線：直角・線：曲線** — 線の描き方を切り替えます（「表示」メニューの「線の形」と同じです）。
- **整列** — 図を自動で並べ直します。

### 図の上の操作

- **図の右上のボタン** — 「＋」拡大、「−」縮小、「全体」全体を表示、「全体図」全体図（右下の小さな図）の表示の切り替え。メニューバーの「表示」にも同じ項目があります。
- **マウスのホイール** で上下左右に動かし、**Ctrl（Mac は ⌘）を押しながらホイール** で拡大・縮小します。タッチでは 2 本指で拡大・縮小します。
- **要素をクリック** で選び、**Shift＋クリック** で選択に加えたり外したりします。要素はドラッグで動かせます。
- **右クリック** で、その場所に合ったメニューを出します。→ [図の操作とエクスポート](/diagrams/editing)

### インスペクタ

要素や線を選ぶと、図の下に出ます。種類（«part def» など）・テキストの行番号・名前と、次の操作が並びます。

- 「テキストで見る」 — テキストのその宣言に移ります。
- 「名前を変更」 — 名前を変えると、テキストの中でその名前を使っている箇所もまとめて変わります。
- 「関係を追加」 — 次にクリックした要素との間に関係を足します。→ [はじめての図](/guide/getting-started#_4-部品を持たせる)
- 「削除」 — もう一度押すと、テキストから削除します。
- フェーズがあるときは、フェーズの選択欄が出ます。部品などの使用では「型の定義へ」も出ます。
- トレースの抜けを案内しているときは、先頭に「△ トレースの抜け 1 / N 件目」・何が足りないか・直し方と、「関係を追加」「テキストで見る」が出ます。「‹」「›」で前後の抜けへ移ります。→ [図で見つけて直す](/diagrams/traceability#図で見つけて直す)

![部品定義 Vacuum を選んだときのインスペクタ](/images/inspector.jpg)

## テキスト

右の欄です。SysML v2 のテキストで、**モデルの正本** です。図やツリーでの操作も、すべてここに書き戻されます。

- 上の行に、ファイル名と、要素と関係の数が出ます。
- キーワード・名前・コメントなどに色が付きます。
- 入力が止まると、図・ツリー・問題一覧に反映します。
- 図で要素を選ぶと、テキストの対応する宣言に印が付きます。図の操作で書き足した行は、しばらく色が付きます。

### 語の説明

テキストの語の意味を、SysML v2 の書き方を知らない人にも分かる言葉で示します。

- **キーワード**（`part def`・`satisfy` など）・**標準のビューの名前**（`GeneralView` など）・**よく使う標準ライブラリの名前** が対象です。
- 語にマウスを乗せると、吹き出しで意味が出ます。
- カーソルのある語の意味は、テキストの下の行に出ます。
- スマホでは、語をダブルタップすると、その語を選んで意味を出します。

![requirement にマウスを乗せると「要求（requirement def）」の説明が出る](/images/word-help.jpg)

### 問題一覧

テキストの下に、モデルの問題を行番号付きで一覧します。押すと、その行に移ります。テキストを直すと消えます。
トレースの抜け（△）の行は、図が見えていれば、図の要求へ移って案内を出します（スマホでテキストのタブを見ているときは、テキストの行へ移ります）。

| 印 | 内容 | 例 |
| --- | --- | --- |
| ⚠ | エラー（書き方の誤り、見つからない型や相手） | 「型「SuctionMoter」が見つかりません（motor）」・「「;」がありません」 |
| △ | トレースの抜け、プラグインのチェック結果（警告） | 「この要求を満たす要素がありません（satisfy）」 |
| ℹ | まだ扱えない書き方、プラグインのチェック結果（情報） | Modelith がまだ読めない書き方を知らせます |

![問題一覧。型の書き間違いと「;」の書き忘れ](/images/problems.jpg)

まだ扱えない書き方は、エラーにせずに「まだ扱えない」と知らせます（一部は知らせずに読み飛ばします）。対応状況は [対応している書き方](/sysml/support) を見てください。

## スマホの画面

幅の狭い画面（幅 760px 以下）は、モデルを **見て確かめるための画面** です。

- 上の「ツリー」「図」「テキスト」で、表示する部分を切り替えます。
- メニューは、左上の「☰」の 1 つにまとまります。押すと「ファイル」「編集」「表示」「図」「プラグイン」「ヘルプ」が縦に並び、見出しを押すと中身が開きます。
- テキストは **読み取り専用** で開くので、触ってもキーボードは出ません。書き換えるときは、テキストの上の「編集」を押します。もう一度押すと読み取り専用に戻ります。
- テキストの語を **ダブルタップ** すると、その語の意味を表示します。
- ＋メニューでは、図の名前の下に SysML v2 の標準のビューの名前を小さく書きます。

## キーボードの操作

Mac では Ctrl の代わりに ⌘ を使います。

| キー | 操作 |
| --- | --- |
| Ctrl+S | 保存 |
| Ctrl+Shift+S | 名前を付けて保存 |
| Ctrl+O | ファイルを開く |
| Ctrl+Z | 元に戻す |
| Ctrl+Shift+Z・Ctrl+Y | やり直す |
| Ctrl+A（図の上） | 図の要素をすべて選ぶ |
| Delete・Backspace | 選んだ要素・線を削除 |
| Esc | 道具・関係の追加をやめる、選択を解く、メニュー（メニューバーのメニュー・「☰」・「＋」など）やエクスポートの画面を閉じる |
| ←・→（メニューを開いている間） | 隣のメニューに切り替える |
| ↑・↓（メニューを開いている間） | 項目を移る |
| スペース＋ドラッグ | 表示範囲を動かす |
| ←・→・Home・End（図のタブの上） | 隣の図・最初の図・最後の図に切り替える |
| ↑・↓（モデルのツリーの上） | 行を移る（スペースで選び、Enter で図を開く） |

Tab キーで、ボタン・図のタブ・モデルのツリーなどの間を移ります。
ダイアログを開いている間は、Tab キーで後ろの画面へは移りません。閉じると、開く前に操作していたボタンへ戻ります。

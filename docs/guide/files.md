# ファイルとフォルダ

Modelith のモデルは、SysML v2 のテキストのファイル（`.sysml`）です。図の配置（要素の位置）は、同じ名前の別のファイル（`.layout.json`）に保存します。
ファイルの操作は、画面左上のメニューバーの「ファイル」と、左のエクスプローラーで行います。

| 操作 | メニュー | キー |
| --- | --- | --- |
| 新しいファイル | ファイル → 新しいファイル（エクスプローラーの「＋」） | |
| ファイルを開く | ファイル → ファイルを開く… | Ctrl+O |
| フォルダを開く | ファイル → フォルダを開く…（Chrome・Edge） | |
| 保存 | ファイル → 保存 | Ctrl+S |
| 名前を付けて保存 | ファイル → 名前を付けて保存… | Ctrl+Shift+S |
| 自動保存 | ファイル → 自動保存（チェックを入れる） | |
| 閉じる | エクスプローラーの「開いているファイル」の「×」 | |

## ブラウザによる違い

| | Chrome・Edge | Safari・Firefox |
| --- | --- | --- |
| フォルダを開く | できます。中のファイルを一覧して、直接編集・上書き保存できます | できません |
| ファイルを開く | ファイルを選んで開き、上書き保存できます | ファイルを読み込みます |
| 保存 | 元のファイルに上書きします | ダウンロードします |
| 図の配置 | フォルダを開いていれば、モデルと一緒に保存します | モデルと配置の 2 つのファイルをダウンロードします |
| [プロジェクト](#プロジェクト) | 使えます | 使えません |

## 新しいファイル

「ファイル → 新しいファイル」で、空のファイル（`untitled-1.sysml` など）を開きます。
まだ保存先が無いので、内容は **このブラウザの下書き** に自動で残ります（次に開いたときに戻ります。中身の無いファイルは残しません）。

フォルダを開いているときは、エクスプローラーのフォルダ名の横の「＋」で、フォルダの中に直接ファイルを作れます。
ファイル名を尋ねるので、`model.sysml` のように最後を `.sysml` にして入れます。`models/a.sysml` のように書くと、フォルダの中のフォルダに作ります。

::: warning 下書きは手元のファイルではありません
下書きは、このブラウザの中にだけあります。ブラウザのデータを消すと失われます。必要なものは「名前を付けて保存」で保存してください。
ブラウザの保存領域がいっぱいで下書きを残せないときは、「下書きを保存できません」と知らせます。そのときは「名前を付けて保存」で保存してください。
:::

## ファイルを開く

「ファイル → ファイルを開く…」（Ctrl+O）で、`.sysml`・`.kerml` のファイルを選んで開きます。

- **Chrome・Edge** — 選んだ 1 つのファイルに、そのまま上書き保存できます。ただし、ファイルを 1 つだけ開いたときは、図の配置を保存する場所がありません。エクスプローラーに「配置は未保存」と出て、保存するときに、そのファイルが入っているフォルダを開くよう案内します。
- **Safari・Firefox** — ファイルを読み込みます（複数のファイルを一度に選べます）。保存はダウンロードになります。モデルと一緒に図の配置のファイル（`.layout.json`）を選ぶと、配置も戻ります。

## フォルダを開く

Chrome・Edge では、「ファイル → フォルダを開く…」（またはエクスプローラーの「フォルダを開く」）で、手元のフォルダを VS Code のように開けます。

- エクスプローラーに、フォルダの中の `.sysml`・`.kerml` のファイルがツリーで並びます。押すと開きます。
- ブラウザが、フォルダの中のファイルを編集してよいかを確かめます。許可すると、上書き保存できるようになります。
- 次に Modelith を開いたときは、そのフォルダと開いていたファイルから始まります。→ [前回の続きから始める](#前回の続きから始める)
- フォルダを開かずに始めたとき（「起動時にサンプルを開く」をオンにしているときなど）は、エクスプローラーの「前回のフォルダ「…」を開く」で、前回のフォルダを開けます（ブラウザの許可を求めます）。
- ほかのアプリでフォルダの中身を変えたときは、「↻」（一覧を更新）を押します。

## 前回の続きから始める

Modelith を開き直すと、前回の続きから始まります。戻るのは次のものです。

- 開いていたフォルダと、その中で開いていたファイル（Chrome・Edge）
- 保存先の無いファイル（新しいファイル・サンプル）。下書きから戻ります
- 表示していたファイルと、図のタブ

### 「前回の続きを開く」

フォルダを読み直すのに、ブラウザの許可が要ることがあります（ブラウザを閉じて開き直したときなど）。
そのときは「前回の続きから始められます」と表示します。「前回の続きを開く」を押して、ブラウザの確認でフォルダの編集を許可すると、続きから始まります。

続きから始めずに別のことをしたいときは、同じ画面の「新しいファイル」・「ファイルを開く」・「フォルダを開く」・「サンプルを開く」を選びます。

### ファイルが見つからないとき

前回開いていたファイルを、そのあと Modelith の外で消したり名前を変えたりしていたときは、そのファイルは開かずに「前回開いていた「…」が見つかりませんでした」と知らせます。ほかのファイルは、そのまま戻ります。
フォルダごと移したり消したりしていたときは、「前回のフォルダ「…」を開けませんでした」と知らせます。

### 起動時にサンプルを開く

前回の続きではなく、いつもサンプルから始めたいときは、「ファイル」メニューの「起動時にサンプルを開く」にチェックを入れます。
保存先の無いファイルは、この設定のときも下書きから戻ります。

## 保存する

「ファイル → 保存」（Ctrl+S）で保存します。

- **保存先のあるファイル** は、元のファイルに上書きします。図の配置も、隣の `.layout.json` に保存します。
- **新しいファイル** は、Chrome・Edge では保存先を選びます。フォルダを開いていなければフォルダを選び、「名前を付けて保存」の画面でファイル名を入れます。Safari・Firefox ではダウンロードします。

「名前を付けて保存…」（Ctrl+Shift+S）は、別の名前で保存します。

### 未保存の変更

未保存の変更があるファイルには、エクスプローラーとテキストの上のファイル名に `●` が付きます。未保存のままページを閉じようとすると、ブラウザが確認します。
ファイルを閉じるときに未保存の変更があれば、「閉じる前に」の画面で「保存する」・「保存しない」・「やめる」を選びます。

### 自動保存

「ファイル → 自動保存」にチェックを入れると、編集が止まってから 1 秒後に自動で保存します。
フォルダの編集の許可が切れたときなど、自動保存できなかったときは「「a.sysml」を自動保存できませんでした：…」と知らせ、未保存の印（`●`）を残します。

### ほかのアプリでファイルが変わったとき

- 画面に戻ったとき、未保存の変更が無いファイルは、変わった内容を読み直します。
- 未保存の変更があるファイルには `⚠` が付きます。保存するときに「ファイルが他で変更されています」の画面が出て、「やめる」・「ファイルの内容を読み込む（自分の変更を捨てる）」・「自分の内容で上書きする」を選びます。黙って上書きすることはありません。
- 図の配置のファイル（`.layout.json`）がほかのアプリで変わっていたときも、保存するときに同じ画面が出ます。

## 図の配置（配置ファイル）

図で動かした要素の位置は、モデルのファイルには書き込まず、同じ名前の別のファイルに保存します。

```text
my-models/
  bicycle-light.sysml         ← モデル（SysML v2 のテキスト）
  bicycle-light.layout.json   ← 図の配置（要素の位置）
```

- まだ配置していない要素は、自動で並べます。
- フォルダを開いていれば、配置もモデルと一緒に保存されます。
- 配置ファイルが無くても、モデルは開けます（図は自動で並べ直されます）。
- モデルのファイルは、利用者が操作したときだけ書き換わります。配置を動かしただけでは、モデルのファイルは変わりません。

::: details 以前のバージョンで保存したファイル
0.1.0-alpha.1 は、図の配置をモデルのファイルの中に書き込んでいました。そのファイルを開くと、配置を別のファイルに移すかを一度だけ尋ねます（「移して整理する」・「そのままにする」）。移さなくても、そのまま使えます。
:::

## 開いているファイルが無いとき

最後のファイルを閉じると、「開いているファイルはありません」と出ます。新しいファイルが勝手に作られることはありません。
ここから「新しいファイル」・「ファイルを開く」・「フォルダを開く」（Chrome・Edge）・「サンプルを開く」を選べます。

![開いているファイルはありません、の画面](/images/files-no-document.jpg)

すべて閉じて終えたときは、次に開いたときも同じ画面から始まります。
サンプルのモデル（電気ケトル）は、いつでも「ファイル → サンプルを開く」で開けます。

## プロジェクト

Chrome・Edge でフォルダを開くと、エクスプローラーのフォルダ名の下に「プロジェクトにする」が出ます。
押してプロジェクト名を入れると、フォルダの一番上に設定ファイル `modelith.json` を作り、エクスプローラーにプロジェクト名を表示します。

```json
{
  "name": "給水システム",
  "plugins": {
    "jp.example.trace": { "version": "0.1.0", "enabled": true }
  }
}
```

- 設定ファイルには、プロジェクト名と、プロジェクトで使うプラグインを書きます。
- フォルダごと Git などで共有すれば、チームの全員が同じ設定とプラグインを使えます。
- 設定ファイルの無いフォルダも、これまでどおり使えます。

プラグインの追加は [チェックルールとプラグイン](/guide/plugins) を見てください。

## 複数のファイル

複数のファイルを開いたまま、エクスプローラーで切り替えられます。未保存の変更は、切り替えても失われません。
いまは **ファイルごとに別々のモデル** として扱います。あるファイルから別のファイルの要素を参照する書き方（`import`）は、まだ使えません（0.2.0 で対応する予定です）。

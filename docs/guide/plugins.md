# チェックルールとプラグイン

プラグインで、Modelith に機能を足せます。いま使えるプラグインは 2 種類です。

| 種類 | できること | プログラム |
| --- | --- | --- |
| **チェックルールのプラグイン** | 「要求には、それを満たす要素が必要」のようなチームの決まりに合わない要素を、問題一覧に示します | 含みません（ルールを YAML で書きます） |
| **画面に機能を追加するプラグイン** | コマンドの実行、モデルのチェック、テキストの変更、ほかの形式のファイルの読み込み・書き出しを足します | 含みます（TypeScript） |

ここでは、プラグインを **使う人** 向けに、追加・有効化・許可の方法を説明します。作り方は [作る人へ](#作る人へ) を見てください。

## プラグインの一覧を開く

「プラグイン → プラグインの一覧…」で、プラグインの一覧を開きます。プロジェクトのフォルダを開いているときは、エクスプローラーの「プラグイン」からも開けます。

一覧には、プラグインごとに次の内容が出ます。

- 名前・追加先（このプロジェクト・このブラウザ）・ID・バージョン
- 状態（有効・エラーあり・未追加・バージョン不一致・無効・プロジェクトを優先）
- ルールやコマンドの数、使う権限、エラーの内容
- 「有効」のチェック、「削除」、画面に機能を追加するプラグインでは「開始」・「停止」・「許可する…」

## プラグインを追加する

1. プラグインのフォルダ（`modelith-plugin.json` のあるフォルダ）を手元に用意します。
2. 一覧の「追加…」を押し、プラグインのフォルダを選びます。
3. プラグインの名前・バージョン・説明（画面に機能を追加するプラグインでは、使う権限）を確かめ、**追加先** を選んで「追加する」を押します。

| 追加先 | 置き場所 | 使える人 |
| --- | --- | --- |
| **このプロジェクト**（既定） | プロジェクトのフォルダの `.modelith/plugins/<ID>/` にコピーし、プロジェクトの設定（`modelith.json`）に登録します | フォルダを Git などで共有すれば、チームの全員 |
| **このブラウザ** | このブラウザの中に保存します | 自分だけ。どのプロジェクトでも、フォルダを開いていなくても使えます |

- 「このプロジェクト」は、Chrome・Edge でフォルダを開いているときに選べます。まだプロジェクトでないフォルダなら、同じ画面でプロジェクトにしてから追加します（プロジェクト名を尋ねます）。
- Safari・Firefox ではフォルダを開けないので、「このブラウザ」に追加します。
- 同じ ID のプラグインが両方にあるときは、プロジェクトのものを使います。このブラウザのものは一覧に「プロジェクトを優先」と出ます。
- zip ファイルからの追加は、まだできません。

### 足りないプラグインの案内

プロジェクトの設定に書いてあるプラグインが追加されていないとき、またはバージョンが違うときは、エクスプローラーと問題一覧でお知らせします。そこから「追加…」で追加できます。

## 有効にする・無効にする・削除する

- 一覧の「有効」のチェックで、有効・無効を切り替えます。無効にしたプラグインのチェック結果は表示されなくなります。プロジェクトのプラグインの切り替えは `modelith.json` に、このブラウザのものはこのブラウザに保存します。
- 「削除」で削除します。このブラウザにデータを保存していたプラグインでは、そのデータを残すか消すかを選べます（既定は残します）。

## チェックの結果を見る

チェックルールの結果は、テキストの下の問題一覧に、どのプラグインのどのルールかを添えて出ます。

```text
⚠ 3 行目：要求「KeepPressure」を満たす要素がありません（プラグイン「トレーサビリティのチェック」のルール req-has-satisfier）
```

- 押すと、その要素の行に移ります。テキストを直すと、チェックし直して消えます。
- ルールやプラグインの設定に誤りがあるときも、ファイルと行を添えて問題一覧と一覧に出します。

## 画面に機能を追加するプラグイン

### 実行の許可

プログラムを含むプラグインは、初めて動かす前に、名前・作者・バージョン・使う権限を示して、**実行してよいかを尋ねます**。

| 画面に出る権限の説明 | マニフェストの値 |
| --- | --- |
| 追加の権限はありません | （なし） |
| 解析したモデル（要素と関係）を受け取り、問題一覧に結果を出す | `model:read` |
| モデルのテキストを変更する（変更は元に戻せます） | `edits:propose` |
| インターネットなど外部と通信する | `network` |
| このブラウザに、プラグイン用のデータを保存する | `storage` |

- 外部と通信できるプラグインは、「このプラグインは、あなたのモデルを外部に送信できます」とはっきり示します。
- 答えは、このブラウザに覚えます。使う権限が増えたとき、または外部と通信できるプラグインのバージョンかファイルが変わったときは、もう一度尋ねます。
- 許可しなかったプラグインは、一覧に「許可されていません」と出ます。「許可する…」で尋ね直せます。

プラグインはアプリから切り離された場所で動き、許可した権限だけを使えます。通信の権限が無いプラグインは外部と通信できず、アプリの下書きや開いているフォルダにも触れられません。

### コマンド・読み込み・書き出し

動いているプラグインが足した機能は、メニューバーの「プラグイン」に、「プラグインの一覧…」の下に並びます。

- **プラグインのコマンド** — コマンドを実行します。プラグインによるテキストの変更は、1 回の「元に戻す」で取り消せます。
- **プラグインで読み込む** — プラグインが対応する形式のファイルを選んで読み込みます。結果は新しい無題のファイルとして開きます（開いているファイルは書き換えません）。
- **プラグインで書き出す** — モデルを、プラグインが対応する形式で書き出し、ダウンロードします。

## 作る人へ

プラグインの作り方は、開発者向けの資料を見てください。

- [チェックルールの書き方](https://github.com/modelith/modelith/blob/dev/docs/reference/check-rules.md) — ルールの YAML の形と置き方

- [plugin-template](https://github.com/modelith/plugin-template) — プラグインのひな形（準備中）

# すべて

モデルのすべての要素と関係を 1 枚に描く図です。新しいモデルを書き始めたときや、全体を見渡したいときに使います。
SysML v2 では GeneralView で描く図に当たります。

![ロボット掃除機の「すべて」の図](/images/diagram-all.jpg)

## 図に出るもの

ほかの図に出る要素と関係は、すべてここにも出ます。次のものは、主にこの図（と一般ビューの作成した図）で見ます。

| 要素・関係 | 描き方 | テキストの例 |
| --- | --- | --- |
| 依存する | 破線と開いた矢印 | `dependency Controller to Battery;` |
| 割り当てる | «allocate» の破線と開いた矢印 | `allocate CleanRoom to Vacuum;` |
| メモ | 角を折った四角と、相手への破線 | `comment c about Battery /* 交換できるようにする */` |
| ポート定義・アイテム定義・列挙定義など | «port def» などの箱 | `port def PowerPort;` |

メモを選ぶと、インスペクタに本文と、メモを付ける相手が出ます。メモは図から削除できます。

## 図で操作する

- パレットには、部品定義・要求・制約定義・関心事・検証・解析・状態定義・アクション定義・属性定義・ポート定義・アイテム定義が並びます。押してから図の上をクリックすると、その要素を置きます。何も無いところの右クリックの「ここに要素を追加」からも置けます。
- 要素を選んで「関係を追加」（または縁の「＋」からドラッグ）で相手を選ぶと、「部品として持つ」・「要求を満たす «satisfy»」などの関係を足せます。足せる関係は [図の操作とエクスポート](/diagrams/editing#要素と関係を足す・変える・消す) を見てください。
- どの種類の要素も置けるので、新しいモデルを図だけで作り始めるときに便利です（[はじめての図](/guide/getting-started) もこの図で進めます）。

## テキストで書く

上の表の書き方で、どの要素も関係もテキストで書けます。依存する・割り当てる・メモは、**図からは足せません。テキストで書きます。** 書いたものは図に描かれ、図で選んで削除できます。

```sysml
dependency Controller to Battery;
allocate CleanRoom to Vacuum;
comment c about Battery /* 交換できるようにする */
```

要素が多くなると見づらくなるので、「新しい図を作成」で、見たい要素だけを集めた図を作ると便利です（[新しい図を作成する](/diagrams/create-diagram)）。

# 図の操作と書き出し

どの図にも共通の操作をまとめます。図での操作は、すべてテキストの書き換えになります（図の配置だけは、配置ファイルに保存します）。
要素を置く・名前を変える・関係を足す・消すといった操作は、テキストを書かずに図だけで行えます。

## 選ぶ

- 要素や線をクリックすると選び、図の下にインスペクタが出ます。テキストの対応する宣言にも印が付きます。
- **Shift＋クリック** で、選択に加えたり外したりします。右クリックの「選択に追加」でも加えられます。
- 何も無いところをドラッグすると、範囲の中の要素を選びます。
- **Ctrl＋A**（Mac は ⌘＋A）か「編集 → すべて選択」で、図の要素をすべて選びます。
- **Esc** で選択を解きます。

## 動かす・並べる

- 要素はドラッグで動かせます。動かした位置は、図の配置として保存されます（[図の配置](/guide/files#図の配置-配置ファイル)）。
- 2 個以上を選ぶと、インスペクタの「左揃え」・「上揃え」・「横に等間隔」・「縦に等間隔」で並べられます（右クリックでは「左を揃える」など）。
- サブバーの「整列」、「図 → 整列」、または何も無いところの右クリックの「この図を並べ直す」で、図を自動で並べ直します。
- サブバーの「線：直角」・「線：曲線」、または「図 → 線を曲線で描く」で、線の描き方を切り替えます（次に開いたときも使います）。

## 表示範囲

- 図の右上の「＋」・「−」で拡大・縮小、「全体」で図の全体を表示します。メニューバーの「表示」の「拡大」・「縮小」・「全体を表示」も同じです。
- マウスのホイールで上下左右に動かし、Ctrl（Mac は ⌘）を押しながらホイールで拡大・縮小します。タッチでは 2 本指で拡大・縮小します。
- パレットの「移動」を選ぶか、スペースキーを押しながらドラッグ（中ボタンのドラッグでも可）すると、表示範囲を動かせます。

### 全体図

図の右上の「全体図」（または「表示 → 全体図」）で、右下に図の全体を小さく表示します（もう一度押すか「×」で閉じます）。いま見ている範囲が枠で示されます。

## 要素と関係を足す・変える・消す

| 操作 | 方法 |
| --- | --- |
| 要素を置く | パレットの道具を押してから、図の上をクリック。何も無いところの右クリックの「ここに要素を追加」からも置けます |
| 関係を足す | 要素を選んで「関係を追加」を押し、相手の要素をクリックして、関係の種類を選ぶ。選んだ要素の縁の「＋」から相手までドラッグしても同じです |
| 名前を変える | インスペクタか右クリックの「名前を変更」。テキストの中でその名前を使っている箇所もまとめて変わります |
| 消す | インスペクタの「削除」（もう一度押して確定）、右クリックの「削除」、または Delete キー。複数を選んで「まとめて削除」もできます |
| テキストで見る | インスペクタか右クリックの「テキストで見る」 |

足せる関係は、2 つの要素の種類で決まります。追加できる関係が無い組み合わせでは、「この組み合わせで追加できる関係はありません」と出ます。

| 選べる関係 | 元 → 先 | テキスト |
| --- | --- | --- |
| 〜として持つ | 定義 → 定義 | `part battery : Battery;` など |
| 要求を満たす «satisfy» | 部品定義・部品 → 要求 | `satisfy R by A;` |
| 要求を検証する «verify» | 検証 → 要求 | `objective { verify R; }` |
| 関心事を扱う «frame» | 要求 → 関心事 | `frame concern c : C;` |
| この要求から導出する «derive» | 要求 → 要求 | `#derivation dependency from A to B;` |
| 信号・物理量を流す（flow） | 部品 → 部品 | `flow from a to b;` |
| この後に実行する（順序 succession） | アクティビティ図の要素どうし | `first a then b;` |
| この状態から遷移する（transition） | 状態遷移図の状態どうし | `transition first a then b;` |

名前は、英字か `_` で始め、英字・数字・`_` だけで付けます。日本語の名前を付けるときは、テキストで `'…'` で囲んで書きます（例：`part def '電池';`）。

## 図に道具の無いもの

次のものは、図からは足したり変えたりできません。**テキストで書きます。** 書いたものは図に描かれ、図で選んだり消したりできます。

| もの | テキストの例 | 詳しく |
| --- | --- | --- |
| 要求の文章 | `doc /* 夜道で 10 m 先まで照らせる */`（要求を図で置くと「ここに要求文を書く」が入るので、そこを書き換えます） | [トレーサビリティ](/diagrams/traceability#テキストで書く) |
| 属性とその値 | `attribute voltage = 3.7;` | [ブロック定義図](/diagrams/block-definition#テキストで書く) |
| 定義を引き継ぐ（特殊化）など | `part def RobotVacuum :> Vacuum;` | [ブロック定義図](/diagrams/block-definition#テキストで書く) |
| 依存・割り当て・メモ | `dependency A to B;`・`allocate A to B;`・`comment c about A /* … */` | [すべて](/diagrams/all#テキストで書く) |
| 制約の式・計算の中身 | `constraint def C { t >= 90 }` | [制御ループ](/diagrams/control-loop#テキストで書く) |
| 接続・結び付け、入れ子の部品とそのポート、部品の名前の変更 | `connect a.p to b.p;`・`bind a.x = b.y;` | [内部ブロック図](/diagrams/internal-block#テキストで書く) |
| アクション・開始・終了・分岐など | `then action sweep;`・`decide d;` | [アクティビティ図](/diagrams/activity#テキストで書く) |
| 状態、遷移のきっかけ・条件・動作 | `state idle;`・`accept StartCommand` | [状態遷移図](/diagrams/state-machine#テキストで書く) |
| イベントとイベントの順序 | `event occurrence press;`・`first a.x then b.y;` | [シーケンス図](/diagrams/sequence#テキストで書く) |
| 保存された図の絞り込み・描き方 | `filter @SysML::PartDefinition;`・`render asTreeDiagram;` | [保存された図](/diagrams/saved-views#テキストで書く) |

## 右クリックのメニュー

![要素を右クリックしたときのメニュー](/images/context-menu.jpg)

| 右クリックした場所 | 主な項目 |
| --- | --- |
| 要素 | テキストで見る・名前を変更・関係を追加…・選択に追加・〜で開く・フェーズ・削除（保存された図では「この図から外す」・「モデルから削除」） |
| 複数選んだ要素 | 左を揃える・上を揃える・横に等間隔で並べる・縦に等間隔で並べる・フェーズをまとめて設定・まとめて削除 |
| 線 | テキストで見る・関係を削除（シーケンス図のメッセージでは、名前・型を編集・上へ移動・下へ移動） |
| ポート・接続点 | 向き（入力・出力・双方向）・ポートを削除、ポートにする…・接続点を外す |
| 何も無いところ | ここに要素を追加（内部ブロック図では「ここに部品を置く」）・すべて選択・この図を並べ直す・全体を表示 |

## 元に戻す

画面左上の「元に戻す」ボタン（左向きに曲がった矢印。Ctrl+Z）で元に戻し、「やり直す」ボタン（右向きに曲がった矢印。Ctrl+Shift+Z・Ctrl+Y）でやり直します。「編集」メニューの「元に戻す」・「やり直す」も同じです。図での操作も、テキストの編集も、同じ履歴に入ります。履歴はファイルごとに持ち、200 段階まで戻れます。

## 書き出す

### SVG で保存

「図 → 図を SVG で保存」で、表示中の図を SVG ファイル（`modelith-structure.svg` など）としてダウンロードします。資料やウェブページに貼れます。

### draw.io 形式で書き出す

「図 → draw.io 形式で書き出す…」で、表示中の図を draw.io で読み込める XML にします。

1. 画面に出た XML を「コピー」します。
2. draw.io（diagrams.net）で「その他 → 図を編集」を開き、内容を貼り付けます。

![draw.io 形式で書き出す画面](/images/export-drawio.jpg)

アクティビティ図・状態遷移図と、シーケンス図のイベントと順序も、記号のまま書き出します。

# 新しい図を作成する

名前と図の種類を選んで、名前の付いた図を作成できます。表示中の図をそのまま残すことも、空の図から見たい要素だけを入れていくことも、ブロックやアクション定義を選んで内部ブロック図やアクティビティ図にすることもできます。一般の図には、あとから要素を入れたり外したりできます。
作成した図は、テキストに SysML v2 の **ビュー（`view`）** として書かれるので、モデルと一緒にファイルに残り、ほかの人とも共有できます。

## 図を作成する

1. 「図」メニューの「新しい図を作成…」を押します。サブバーの「新しい図を作成」や、サイドバーの「図」のタブの「＋ 新しい図を作成…」からも同じ画面が開きます。
2. 「新しい図を作成」の画面で、図の名前を入れ、図の種類を選びます。
3. 「作成」を押します（描く対象を選ぶ種類では「次へ」）。

![新しい図を作成の画面。図の名前に「構成の概要」と入れたところ](/images/new-diagram-dialog.jpg)

| 図の種類 | できる図 |
| --- | --- |
| 今の図のまま（表示中の図の名前） | 表示中の図の要素と配置のまま作成します。自動で描く図（ブロック定義図など）を表示していて、図に要素があるときだけ出ます |
| 一般の図（ブロック定義図・要求図） | 空の図から始めます。モデルのツリーから要素を入れて並べます |
| 内部ブロック図 | ブロックの中の部品と、そのつながりを描きます |
| アクティビティ図 | アクション定義の流れを描きます |
| 状態遷移図 | 状態定義の状態と遷移を描きます |
| シーケンス図 | シナリオの中のメッセージのやり取りを描きます |

作成した図は新しいタブで開き、サイドバーの「図」のタブにも並びます。

### 今の図のまま作成する

自動で描く図（ブロック定義図など）を表示して「今の図のまま」を選ぶと、いまの図の要素と配置のまま、名前の付いた図ができます。テキストには、次のような `view` が書き足されます。

```sysml
view '構成の概要' : GeneralView {
    expose RobotVacuum::Battery;
    expose RobotVacuum::SuctionMotor;
    expose RobotVacuum::Controller;
    expose RobotVacuum::Vacuum;
    expose RobotVacuum::User;
    expose RobotVacuum::PhoneApp;
}
```

`expose` は「この要素を図に出す」という意味です。日本語などの名前は `'…'` で囲みます。図の配置も、作成した時点の配置を引き継ぎます。

![作成した図「構成の概要」を開いたところ。テキストに view が足されている](/images/created-diagram.jpg)

内部ブロック図・シーケンス図・アクティビティ図・状態遷移図を表示して「今の図のまま」を選ぶと、その図の対象を `expose` した、それぞれの種類の `view` になります。

### 空の図から始める

「一般の図（ブロック定義図・要求図）」を選ぶと、要素の無い空の図ができます。「空の図「…」を作成しました。モデルのツリーから要素を入れてください」と出るので、次の [要素を入れる・外す](#要素を入れる・外す) の操作で、見たい要素を入れて並べます。

### 描く対象を選ぶ

「内部ブロック図」・「アクティビティ図」・「状態遷移図」・「シーケンス図」を選んで「次へ」を押すと、その図に描く対象を選ぶ画面が出ます。

| 図の種類 | 選ぶ対象 |
| --- | --- |
| 内部ブロック図 | ブロック（部品定義） |
| アクティビティ図 | アクション定義 |
| 状態遷移図 | 状態定義 |
| シーケンス図 | シナリオ |

- モデルにある対象が、名前の順に並びます。選んで「作成」を押すと、その対象の図ができます。
- 最後の「新しいブロックを作る」（アクティビティ図なら「新しいアクション定義を作る」など）を選んで「作って作成」を押すと、モデルに新しい対象を足して、その図にします。名前はあとから変えられます。モデルにまだ対象が無いときは、この項目だけが出ます。

テキストには、選んだ対象を `expose` した `view` が書き足されます（例：内部ブロック図なら `view 名前 : InterconnectionView { expose Vacuum; }`）。

## サイドバーの「図」

サイドバーの「図」のタブに、作成した図が並びます。行には、図の名前と種類（一般ビュー・内部ブロック図など）が出ます。表示中の図の行には印が付きます。

- **開く** — 行を押すと、その図が開きます（Enter でも開きます）。
- **名前の変更** — 行の「名前」ボタンか、行を右クリックして「名前を変更」を選ぶか、行を選んで F2 を押します。「図の名前を変更」の画面で新しい名前を入れ、「変更」を押します。テキストの `view` の名前が変わり、図の配置と開いているタブもそのまま新しい名前に移ります。
- **削除** — 行の「削除」ボタンか、行を右クリックして「削除」を選ぶか、行を選んで Delete キーを押します。「図を削除」の画面で「削除」を押すと、テキストの `view` を消して、その図のタブを閉じます。図に出していた要素は、モデルに残ります。
- 「＋ 新しい図を作成…」で、新しい図を作成します。

キーボードでは、上下の矢印キーで行を移ります。
モデルのツリーで作成した図の行を右クリックしても、「図の名前を変更」・「図を削除」を選べます。

## 作成した図を開く

- サイドバーの「図」のタブの行を押します。
- 図のタブの「＋」のメニューの「作成した図」の見出しの下から開きます（「自動で描く図」の見出しの下には、組み込みの図が並びます）。
- モデルのツリーにも、作成した図が出ます。「開く」で開けます。

作成した図のタブでは、サブバーに「作成した図「構成の概要」：一般ビュー」のように、名前と図の種類が出ます。

## 要素を入れる・外す

一般ビューの作成した図（「一般の図」を選んで作成した図と、ブロック定義図・トレーサビリティ・すべてなどから「今の図のまま」で作成した図）では、図に出す要素を変えられます。

- **入れる** — パレットから要素を置くと、モデルに要素を足して、この図にも入れます。モデルのツリーから要素を図にドラッグするか、ツリーの行の「追加」（右クリックでは「この図に入れる」）を押すと、既にある要素をこの図に入れます。
- **外す** — 要素を右クリックして「この図から外す」を選びます。図から外しても、モデルの要素は消えません。モデルから消すときは「モデルから削除」を選びます。

テキストでは、`expose` の行が足されたり消えたりします。

## テキストで書く

`view` はテキストで書くこともできます。書いた `view` も作成した図になり、＋メニューの「作成した図」から開けます。
種類での絞り込み（`filter`）・描き方（`render`）・パッケージを枠で囲む図は、**図からは作れません。テキストで書きます。**

```sysml
// パッケージの中のすべての要素を出す
view AllParts : GeneralView {
    expose RobotVacuum::*;
}

// 種類で絞り込む（部品定義とポート定義だけ）
view PartsAndPorts : GeneralView {
    expose RobotVacuum::*;
    filter @SysML::PartDefinition or @SysML::PortDefinition;
}

// 内部ブロック図
view VacuumInside : InterconnectionView {
    expose Vacuum;
}
```

| 書くもの | 意味 |
| --- | --- |
| `view 名前 : 種類 { … }` | 図。種類は下の表の標準のビュー。種類を書かなければ一般ビューになります |
| `expose A;` | 要素 A を図に出す。`P::*` はパッケージ P の中の要素、`P::**` は入れ子の中まですべて |
| `filter 条件;` | 出す要素を絞り込む。`@SysML::PartDefinition` のような種類や、`and`・`or`・`xor`・`not`・括弧、`istype`・`hastype` で組み合わせます |
| `render asTreeDiagram;` | 描き方を決める（`asTreeDiagram` はノードと線の図、`asInterconnectionDiagram` は内部ブロック図） |

| 標準のビュー | 画面での名前 | 描き方 |
| --- | --- | --- |
| `GeneralView` | 一般ビュー | ノードと線の図 |
| `InterconnectionView` | 内部ブロック図 | `expose` した部品定義の中身 |
| `ActionFlowView` | アクティビティ図 | `expose` したアクション定義の流れ |
| `StateTransitionView` | 状態遷移図 | `expose` した状態定義の状態と遷移 |
| `SequenceView` | シーケンス図 | `expose` したシナリオ |

`GeometryView`・`GridView`・`BrowserView` は、まだ専用の描き方が無く、ノードと線の図で代わりに描きます（そのことを問題一覧で知らせます）。

### パッケージを枠で囲む

作成した図に、パッケージそのものを `expose` すると、パッケージを名前付きの枠（フォルダの形）で描き、中の要素を枠の中に並べます。パッケージの中のパッケージは、枠の中の枠になります。

```sysml
package Home {
    package Drive {
        part def Motor;
        part def Wheel;
    }
    part def Body;

    view Layout : GeneralView {
        expose Home::Drive;
        expose Home::Body;
    }
}
```

## ほかのファイルの要素を出す

フォルダを開いているときは、フォルダの中のほかのファイルの要素も `expose` できます（[複数のファイル](/next/guide/files#複数のファイル)）。
ほかのファイルの一番上の要素はその名前で、パッケージの中の要素は `import` で取り込んだ名前か `Parts::Wheel` のような名前で書きます。
図には、ほかのファイルの要素に、ファイル名の札を付けて描きます。

モデルのツリーには表示中のファイルの要素だけが出るので、ほかのファイルの要素を図に入れるときは、テキストで `expose` を書きます。

```sysml
package Bicycle {
    import Parts::*;
    part def Bike {
        part front : Wheel;
    }
    view Overview : GeneralView {
        expose Bike;
        expose Wheel;    // parts.sysml の Parts::Wheel
    }
}
```

## できないこと

- メタデータの値を比べる `filter`（`level > 1` など）は使えません（0.3.0 以降の予定です）。
- ほかのファイルに書いた別名（`alias`）は、`expose` に使えません。

# ブロック定義図

部品の型（部品定義）と、その間の関係を見る図です。システムがどんな部品からできているかを、上から下へ段に分けて描きます。
SysML v1 のブロック定義図（bdd）に当たり、SysML v2 では GeneralView で描く図です。

![ロボット掃除機のブロック定義図。Vacuum が battery・motor・controller を部品として持つ](/images/diagram-block-definition.jpg)

## 図に出るもの

| 要素 | 箱 |
| --- | --- |
| 部品定義（`part def`） | «part def» の箱。中に属性（`capacity = 3000` など）の行が並び、ポートは縁の小さな四角で描きます |
| パッケージの直下の部品（`part`） | «part» の箱 |
| 属性定義（`attribute def`） | «attribute def» の箱 |

どの定義の箱にも、説明（`doc`）を区画に書きます。満たすべき制約（`assert constraint`）を書いた定義には、その式も `assert { … }` と書きます。

| 関係 | 線 | テキストの例 |
| --- | --- | --- |
| 部品として持つ | 実線。部品の名前と多重度（`[4]` など）を線の端に書きます | `part def Vacuum { part battery : Battery; }` |
| 定義を引き継ぐ（特殊化） | 白抜きの三角の矢印 | `part def RobotVacuum :> Vacuum;` |
| 一部になる（部分集合）・置き換える（再定義）・参照する | 白抜きの三角の矢印（再定義は縦棒、参照は 2 つの点を添えます） | `:>`・`:>>`・`::>` |

所有の深さで段を分けるので、全体を表す部品定義が上に、部品が下に並びます。

[すべて](/next/diagrams/all) の図と、作成した一般の図には、次のものも出ます。

| もの | 描き方 | テキストの例 |
| --- | --- | --- |
| パッケージの直下のアクション・アイテム・状態 | «action»・«item»・«state» の箱 | `action brew : Brew;`・`item water : Water;` |
| 別の言語での表し方（`rep`） | 角を折った四角に «rep» と言語を見出しにしたメモ。持ち主の要素へ破線を引きます | 下の例 |

## 図で操作する

- パレットの「部品定義」・「属性定義」・「ポート定義」・「アイテム定義」で要素を置けます。置くと名前の入力欄が出ます。
- 部品定義を選んで「関係を追加」で別の定義を選ぶと、「部品として持つ」などを選べます。テキストには `part battery : Battery;` のような行が足されます（部品の名前は型の名前から自動で付きます）。
- 選んだ要素の縁に出る「＋」から、相手の要素までドラッグしても関係を足せます。
- 線を選んで Delete キー（または右クリックの「関係を削除」）で、関係を消せます。
- 定義を選ぶと、インスペクタで説明（`doc`）と属性を編集できます。「説明を編集」で説明を書き、「属性」の欄の「属性を追加」・「編集」・「削除」で属性とその値を変えます。→ [インスペクタ](/next/guide/screen#インスペクタ)

## テキストで書く

次のものは、**図からは足せません。テキストで書きます。**

- 定義を引き継ぐ（特殊化）・一部になる・置き換える・参照する（`:>`・`:>>`・`::>`）
- 部品の多重度（`part wheels : Wheel[4];`）
- 別の言語での表し方（`rep`）

属性とその値（`attribute capacity = 3000;`）は、インスペクタでもテキストでも書けます。書いた属性は、箱の中の行に出ます。

```sysml
part def Battery {
    attribute capacity = 3000;
}
part def Vacuum {
    part battery : Battery;
    part wheels : Wheel[4];
}
part def RobotVacuum :> Vacuum;

part def Controller {
    doc /* 掃除の手順を決める */
    rep inOCL language "OCL" /* self.battery.capacity > 0 */
}
```

ポートの向きの変更や、線の端をポートにする操作は [内部ブロック図](/next/diagrams/internal-block#ポート) を見てください。
